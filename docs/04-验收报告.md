## 四、本轮修掉的两个真实缺陷

1. **倍率取到 0**：萤石终结技、洛茜战技因黑板 key 命名为 `atk_scale_total` / `atk_scale_once`，
   旧逻辑只认 `atk_scale` → 伤害恒为 0（等于这两个技能不存在）。
   修法：`_resolve_mult` 增加命名兜底链。修完后洛茜进入 Top1 队。
2. **热启动轴可能比冷启动差**：搜索是启发式的，"开场倾泻终结技"只是启发式起点。
   修法：新增 `search_pair` —— 冷启动选出的完整动作序列在热启动条件下**同样合法**，
   重放一次得到热启动下界，与搜索结果取优。单测 `test_hot_not_worse_than_cold` 守住。

## 五、明确的已知不足（不掩盖）

| 项 | 现状 | 影响 |
|---|---|---|
| 绝对伤害偏低 | 未建模 buff/debuff、元素与物理异常伤害、武器装备 | 只能做相对排序 |
| 热启动增益偏小 | 终结技的时间停止、专属增伤未建模 | 热启动优势被低估 |
| 多段技能口径 | 与 wiki「效果1」有 ~14% 项不一致 | 已定位为多组成部分差异，报告可见 |
| 6 个技能倍率为 0 | 赛希/昼雪/秋栗/安塔尔/庄方宜等，多为护盾/治疗或召唤类 | 这些角色被低估 |
| 常量 | 技力恢复、切人开销、连携窗口帧数仍是估计 | 需要实测或日志反推 |
| 打包 | 未生成 exe；桌面壳依赖本机 Python | 双击 `desktop\start.cmd` 可用 |
