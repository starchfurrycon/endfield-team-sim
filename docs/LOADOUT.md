从旧版"按面板属性拍脑袋"改成**整套 + 模拟**的推荐。

## 为什么之前会错

- 武器只按 `ATK + ATK% + 主属性` 排，楔子的主属性权重被放大，
  专武的暴击/元素被动完全没进分；于是出现"楔子第一"。
- 装备逐件挑属性，没有把"同套 3/4 件"作为约束，所以经常凑不出套装效果。
- 每个角色给"输出/功能"两套，但队伍固定时角色定位是固定的，两套是伪选择。

## 现在的算法

1. **定位固定**：按 `battle_tags` / 职业定主 C / 辅助 / 生存 / 治疗，
   一个角色只出一套装备，不再分输出/功能。
2. **武器**：
   - curated 表里的**专武**排第 1、**大月卡下位**排第 2（引擎尚未建模的被动用先验兜底）；
   - 其余武器按 `ATK + 主属性 + 暴击/元素被动折算` 排序；
   - 用队伍模拟做坐标下降，确认换武器是否真的提升总伤。
3. **装备**：
   - 只枚举**能触发套装被动**的 3/4 件组合；
   - 同套优先补满 4 槽，凑不齐才跨套，但必须满足 `need` 件；
   - 每个角色固定一套，整队一起模拟。
4. **搜索**：候选空间大，用坐标下降 + 缓存：
   固定其他 3 人，逐个换武器/套装，只接受队伍总伤提升的方案；
   两轮不提升即停。

## 示例（伊冯）

- 武器：`艺术暴君`（专武）→ `作品：众生`（大月卡下位）→ `领航者` / `楔子`
- 装备：`M.I.警用护甲` 暴击套（3 件套：暴击+5% / 攻击+5% / 暴击+5%）

## 已知限制

- 引擎只实现了部分武器被动（暴击/元素伤害靠折算先验），
  所以专武/大月卡用 curated 表强制优先；后续会把被动逐条接进伤害公式。
- 坐标下降是局部最优，不是全枚举的全局最优；步长受 `beam/steps` 限制。
- 套装被动里条件型（叠层/持续）暂按触发一次估算。
