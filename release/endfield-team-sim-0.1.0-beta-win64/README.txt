终末地配队模拟 v0.1.0-beta（Windows x64，免安装）
================================================

【怎么用】
1. 双击 endfield-server.exe
2. 首次启动会自动从社区数据仓拉取并构建数据集（需要联网，约 1~3 分钟）
3. 构建完成后浏览器会自动打开 http://127.0.0.1:8777/
   —— 如果没自动打开，手动在浏览器里访问这个地址
4. 左侧点干员：点一次 = 必须包含，点两次 = 禁止，点三次 = 清除
5. 点“推荐配队”，右侧出现队伍卡片；每张卡可切换“冷启动轴 / 热启动轴”

【想换端口】
  endfield-server.exe 8899

【想更新游戏版本数据】
  关掉程序，删除同目录下的 data 文件夹，再启动即可重新构建。

【重要：数值怎么用】
  这是“排序器”，不是伤害真值机。
  未建模：buff/debuff、元素异常与物理异常伤害、武器与装备加成。
  所以请用它比较“哪队更好 / 哪条轴更顺”，不要拿绝对 DPS 去对比别处。

【已知限制】
  - 自然技力恢复速率（8 点/秒）是估计值，客户端表里只有修正项，基础速率未随表导出。
  - 热启动收益可能被低估：终结技的时间停止与专属增伤未建模。
  - 敌人行为是“固定间隔出手”的场景参数，不是真实 AI。

【数据与许可】
  本程序不含任何游戏数据；运行时从公开社区镜像抓取并缓存在本地 data 目录。
